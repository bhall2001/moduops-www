# Station Order

The station order is the order your Modules/Towns are listed on the [String Diagram and Timetable Report](timetable-reports.md). It usually follows the order stations sit along the main line, from one end of the layout to the other.

There is one station order for the whole layout. Every ops session uses it.

## What station order controls

On the String Diagram, stations run down the side of the chart in station order, so getting the order right is what makes each train draw as a clean line from one end of the layout to the other. On the Timetable Report, the rows are listed in station order.

Station order does not change train routes, trainlists or the order stops appear in a train instance.

## Editing the station order

1. Click `Timetable` in the sidebar menu.
2. Click `Edit Station Order`.
3. Drag each Module/Town by its handle into place. The list shows every Module/Town in the layout, with its short name underneath when it differs from the name.
4. Click `Save`.

You can also move a Module/Town with the keyboard by focusing its drag handle.

While you have changes that are not saved, the screen shows "You have unsaved changes". If you try to leave before saving, ModuOps asks whether you want to `Stay on Page` or `Leave Page`.

Click `Back to Timetable` to return to the Timetable screen.

### Reset to Default

Once a station order has been saved, a `Reset to Default` button is available. It sorts the list alphabetically. Click `Save` to keep the alphabetical order.

## Before you save a station order

Until you save a station order, the String Diagram and Timetable Report pick an order for you, based on the order stations appear in your trains' routes. This is a reasonable starting point, but saving your own order gives you control over how the diagram and report look.

The first time you open the Station Order screen, Modules/Towns are listed alphabetically.

## Adding new Modules/Towns

:::tip
After you add new Modules/Towns to the layout, open `Edit Station Order`, drag the new Modules/Towns into place and click `Save`. Once a station order is saved, new Modules/Towns do not appear on the String Diagram or Timetable Report until you save the station order again.
:::

New Modules/Towns are listed at the bottom of the Station Order screen, in alphabetical order, until you move them.
